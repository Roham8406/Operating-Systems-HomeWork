
\begin{itemize}
	\small
	\setlength\itemsep{0.05em}
	\item
	در طول ترم امکان ارسال با تاخیر پاسخ تمارین وجود ندارد. 
	\item
    همکاری با دیگر دانشجویان درس برای انجام تمرین مجاز نیست. 
    \item 
    در استفاده از هر منبع خارج درس، آدرس منابع مورد استفاده برای حل سوال مورد نظر را ذکر کنید.
    \item 
    لطفا تصویری واضح از پاسخ سوالات نظری بارگذاری کنید.در غیر این صورت پاسخ
    شما تصحیح نخواهد شد.
    
\end{itemize}
